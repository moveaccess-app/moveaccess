# 🚀 Quick Reference - Encontrando Seus Custom Agents

## ⚡ Resposta Rápida

**Seus custom agents do GitHub Copilot NÃO estão no repositório!**

Eles estão armazenados no GitHub, no nível da sua conta/organização.

## 📍 Onde Encontrar

### 🔗 Links Diretos

- **Conta Pessoal:** https://github.com/settings/copilot/agents
- **Organização:** https://github.com/organizations/[SUA-ORG]/settings/copilot/agents

### 🛠️ Via Interface

1. GitHub.com → Settings
2. Copilot (menu lateral esquerdo)
3. Custom agents

## 🔍 Procurando "MoveAccess Feature Executor Agent"?

1. Acesse: https://github.com/settings/copilot/agents
2. Use o campo de busca ou role a lista
3. Clique no agent para editar/visualizar

## ❓ FAQ Rápido

**P: Por que não vejo o agent no repo?**  
R: Agents são configurações do GitHub, não arquivos de código.

**P: Como compartilhar com o time?**  
R: Crie o agent no nível da organização, não na conta pessoal.

**P: Posso versionar agents no Git?**  
R: Não diretamente, mas você pode documentar as instruções do agent no repo.

**P: Onde fica `.github/copilot-instructions.md`?**  
R: Esse arquivo SIM fica no repo e contém instruções gerais (não agents).
